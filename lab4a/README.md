# Module 4a: Web Server, Application Frameworks & Cloud Services Setup

## Overview
This module demonstrates the setup, service management, and dependency verification for Linux-based web servers, web application environments (Flask & Express), SSL tooling (Certbot), and Cloud-Init initialization logs.

## Verified Services & Components
- **Apache Web Server**: Verified active service status using `systemctl status apache2`.
- **SSL / Security Tooling**: Installed and verified Certbot (`certbot --version`).
- **Web Frameworks & Runtimes**: Verified Python Flask (`3.1.3`) and Node.js Express (`5.2.1`) package installations.
- **System Initialization**: Inspected cloud initialization logs via `cloud-init status` and `/var/log/cloud-init.log`.
